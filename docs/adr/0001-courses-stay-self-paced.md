# Courses stay self-paced; only Yilmu's AI-drafting chain is adopted

Courses stay self-paced: Learners join any time, open Lessons in any order, and an Exam unlocks once every Lesson is complete. From Yilmu (a Malaysian school planning platform) we adopt only its plan → AI draft → human review chain, mapped as: Brief → AI writes a Course Outline (Draft Lessons with titles and Objectives) → AI writes each Lesson's text → AI writes Exam questions from published Lessons → Admin reviews and publishes Drafts. We do not adopt Yilmu's school calendar, weeks, weekly timetable or school-staff model, and we add no new user role; the Admin stays the only person who builds Courses. Rejected: (1) Courses with a weekly schedule like Yilmu's timetable, which would change the agreed rules for Enrollment, progress and when the Exam unlocks; (2) a separate school planning product alongside Courses, which would be a second user type and effectively a second product. The client's real need was AI help writing content, not scheduling. If the client later runs cohort programmes with fixed dates, that is a new decision and reopens this ADR.
