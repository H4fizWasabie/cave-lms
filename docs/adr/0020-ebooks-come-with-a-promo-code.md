# Ebooks come with a Promo's code, not with a product

Ebooks are a lure for new buyers, so they are not a benefit of CaveText Pro, the Lab Plan or the Pro Plan at full price. A Learner gets Ebook access by paying for the Pro Plan with the code of a Promo the Admin marked "comes with Ebooks" (CAVE99 at launch), or when the Admin gives the COMBO Pro Plan by hand. It lasts as long as the year of CaveText Pro that payment bought, and ends when that year does or when the Admin ends their Pro; renewing at full price does not extend it. Every ebook that is not Promotional material needs it to be opened or downloaded; Visibility still decides who sees the ebook listed, so Learners without it, and Visitors, see a locked ebook pointing to the COMBO Pro Plan.

This rests on BCL's payment webhook naming the coupon code a payer typed (`coupon_code`, seen on a real Test Mode order). Live orders are read from BCL's order detail, which may or may not name the coupon: no live order has shown it yet. A detail without a code never opens Ebooks on the webhook's: if the webhook names a running Ebooks Promo's code, the order is kept for an Admin and gives nothing, and any other code is as none. BCL's own discount is what is checked against the Promo price. Payments before this change are not read again, so none of them gives Ebook access.

Learners read an ebook in the browser, in a reader on its page, and cannot download it from the site; only Admins can. Promotional material stays downloadable. This is deterrence, not DRM: a browser that shows a PDF can still save it. Watermarking each Learner's copy, or a server-rendered viewer, would be the upgrade if leaks matter.

Changed 2026-10-29: a buyer should get the ebooks to keep, not only to read in the Gallery. Attaching them failed: Resend answered 408 after 59 seconds for an email carrying the 14 MB ebook. So the Ebook email carries an Ebook download link for each ebook that is not Promotional material, as the Gallery holds them when it is sent: one click downloads the PDF, with no sign-in, for 7 days, and only while that Learner's Ebook access runs. We accept that a downloaded copy can be shared and outlives the year, and that a forwarded link works for anyone until it expires; the site stays read-only and its access still ends with the year. An expired link points to the Gallery; the Admin resends the Ebook email for fresh links, and for an ebook uploaded after a buyer's email.

Rejected: (1) ebooks for every paid Learner, or every Pro Plan holder, which gives away what the COMBO card sells; (2) deciding by the price paid, which cannot tell one Promo from another; (3) a `paid` Visibility set on each item, a second setting the Admin would have to remember on every upload.
