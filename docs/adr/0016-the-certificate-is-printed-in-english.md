# The Certificate is printed in English

An exception to ADR 0005, from the Premium refresh (#307). The Certificate's artwork, the wording its PDF prints and its web preview are English only, like the client's sample Certificate (PCC-2026-00509), whatever language the page or the Learner uses: a Certificate is one document, shown to employers and HRD Corp, and the client's design sets its wording in English. So the fixed wording (the title, "This is to certify that", the awarding paragraph, the signatories, "Certificate No.", "Issued on", "REVOKED" and the revoked note) is not in the text catalog. It lives once, in Go beside the artwork (`certificate_artwork.go`), and both the PDF and the preview print it from there, with the same coordinates, so the two cannot drift. The pages around the preview, its caption and the placeholder name a Visitor sees stay in both languages from the catalog. Rejected: a Malay Certificate, which the client did not ask for and would need a second artwork; the wording in the catalog with the Malay set equal to the English, which hides the decision and invites a translation that would not match the printed document.
