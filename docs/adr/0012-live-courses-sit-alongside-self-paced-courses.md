# Live Courses sit alongside self-paced Courses

The client runs Courses for companies on agreed dates, 1 to 5 days, several in a month, so the Admin can duplicate a Course into a Live Course with a start date, an end date and a number of days. This reopens ADR 0001, as it said a dated cohort would. Live Courses are added beside self-paced Courses, not in place of them: a self-paced Course keeps every ADR 0001 rule. A Live Course can be joined while published and until the end of its end date, Malaysia time; after that it shows as closed and stays viewable. Its days, not its dates, set its PCC Level, because a 2-day Course may be spread over a Tuesday and a Thursday. Duplicating copies the Lessons and the Exams with their questions, as the Question bank copies questions into an Exam, so one company's copy never changes another's; Learners, attempts and Certificates stay with the original. The copy starts as a Draft Course, which only the Admin sees until it is published. Rejected: (1) one Course with several dated runs, which would make Enrollments, Results and Certificates name a run as well as a Course everywhere; (2) dated Courses replacing self-paced ones, which the client still sells.

**Update, 29 Oct 2026:** the Admin can also create a Live Course directly from New Course, choosing Live Course instead of Self-paced and filling in its dates, days and Organisation, not only by duplicating a Course. A Course stays the kind it was made as.
