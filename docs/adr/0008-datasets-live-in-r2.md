# Datasets live in Cloudflare R2, not Postgres

Each Learner gets a 1 GB Storage allowance for a year, and the target is tens of thousands of Learners: up to 20 TB in the worst case, far beyond one VPS disk or a Postgres database on it. Dataset data therefore lives in Cloudflare R2, and Postgres keeps only the records (which Dataset belongs to which Dashboard, its file name and size). R2 charges nothing for downloads, so a popular Deployment costs the same as an unseen one, and Cloudflare's edge serves a Deployment's data from near the viewer instead of from the VPS. Rejected: (1) keeping Datasets as JSON in Postgres, as before, which ties storage to the VPS and makes every backup grow with it; (2) the VPS disk, the same limit; (3) S3 or other object stores, which charge for downloads. The VPS keeps running the LMS only, so it can stay small.
