# Dashboards come only from Templates; Learners never supply code

Amended by ADR 0013: in a Work Dashboard the Learner may change the blocks as configuration, never code.

Every Dashboard is generated by Cave from a Template, filled with the Learner's Dataset and column choices. Learners never paste, upload or edit code, and no AI writes dashboard code. Learners are office staff with no coding experience; Templates give them a dashboard that cannot break, costs nothing per build, and keeps the data separate from the design, so re-uploading a Dataset updates the Dashboard without regenerating anything. Rejected: (1) Learners pasting HTML that ChatGPT wrote for them, which puts strangers' scripts on our domain and tends to bake the data into the page, the fragility this feature exists to fix; (2) AI generation inside Cave (such as OpenRouter's free models), whose limits are shared across every Learner and whose models come and go; (3) a hosted Streamlit app per Dashboard, one always-running process each, about 60 before the VPS is full, and running AI-written code on the server. Customising is limited to what Templates offer; that is the accepted cost. AI may return later to pick a Template and column mapping, never to write the code; letting Learners edit the generated code reopens this ADR and ADR 0004.
