# Learners' Workbooks are kept in their Folder

Amends ADR 0008 and ADR 0018. Until now Cave cleaned a Learner's Excel upload into a Dataset and threw the file away. The client wants the Folder to be the Learner's own private place for what they bring to the Lab, so the Excel file is now kept as uploaded, as a Workbook, in the same R2 bucket and keyed by Learner, as soon as it is uploaded, whether or not the Learner confirms its Clean-up. A Workbook can be uploaded in the Folder or on a Dashboard, which drops it in the Folder too, and a Dashboard picks a Workbook to clean into its Dataset. Clean-up stays: Deployments read `data.json` and Cave-built Dashboards read the Dataset (ADR 0017, ADR 0019), never the Excel file. A Dataset still belongs to one Dashboard, so two Dashboards using one Workbook each keep their own, and deleting a Workbook leaves its Datasets and Deployments working.

Workbooks count against the Storage allowance alongside the Datasets cleaned from them, so one upload takes room twice; that is the honest count and keeps one rule. Only a Learner with an active Plan can add a Workbook, as only they have a Lab; Submissions stay outside the allowance. When the last Plan period ends, the Folder is read-only for the 90 days before deletion, so a Learner can download their Workbooks. The Folder also lists each Dashboard's pages, linked to the Dashboard; pages are still uploaded on the Deploy tab. Existing Datasets have no Workbook and none is made up for them. A Workbook that fit the allowance only because the Parts its upload would replace count as free is not kept if the upload then comes to nothing, as those Parts are still held.

Rejected: (1) keeping only the Workbook and dropping Clean-up, which loses the live data Deployments read and that the client sells; (2) a Workbook tied to one Dashboard, which cannot be reused and leaves the Folder a mirror of the Lab; (3) counting only the Workbook or only the Dataset, which lets one side grow unchecked; (4) counting Submissions too, which free Learners, with no allowance, could not upload.
