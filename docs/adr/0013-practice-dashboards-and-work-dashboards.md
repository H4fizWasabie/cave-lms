# The Lab has Practice Dashboards and Work Dashboards

The Lab now has two kinds of Dashboard, both built from Templates and both deployable. A Practice Dashboard is today's Template Dashboard, kept as it is for the Courses: fixed blocks, clean Samples, and code to look at under the hood. A Work Dashboard is for a Learner's real spreadsheets: Clean-up, several sheets combined, earlier Datasets kept, and blocks the Learner can change. Real files need all of that, but it would make the teaching flow less predictable and harder to explain. This amends ADR 0003 for Work Dashboards only: a Learner may change their blocks, but a change is configuration that Cave applies, never code, and no AI writes code. Rejected: one kind for everything, which loads the Courses with real-data machinery; only Work Dashboards deploying, which breaks existing Deployments and the Courses' last step; turning a Practice Dashboard into a Work Dashboard, left out of v1.
